# Contributing

Thank you for contributing to AI Maintainer OS.

## Good first contributions

- Improve issue classification rules
- Add test cases
- Improve documentation
- Add GitHub Action examples
- Add MCP examples

## Development

```bash
pnpm install
pnpm build
pnpm test
```

## Pull request expectations

- Keep changes focused
- Add tests for logic changes
- Explain maintainer-impact in the PR body
