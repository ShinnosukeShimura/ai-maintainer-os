## One-line description

An open-source AI operating system for issue triage, pull-request intelligence,
repository health, contributor analytics, and maintainer sustainability.

## Project summary

AI Maintainer OS helps open-source maintainers reduce repetitive operational work.
It provides a CLI, GitHub Action, MCP server, and Discord bot for issue triage,
pull request review, weekly repository reports, contributor-health monitoring,
and maintainer burnout-risk detection.

The project is designed to keep maintainers in control. It does not auto-merge
or make irreversible changes. It suggests labels, summarizes risk, and produces
auditable recommendations.

## Why this matters

Open-source maintainers often perform a large amount of unpaid operational labor:
triaging issues, answering repeated questions, reviewing pull requests, labeling
work, and managing community expectations.

AI Maintainer OS targets this maintenance burden directly. The goal is to improve
open-source sustainability by reducing repetitive queue-management work and helping
maintainers focus on the parts of the project that require human judgment.
